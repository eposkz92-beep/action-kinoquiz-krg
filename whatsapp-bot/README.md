# 🎬 WhatsApp Бот для ACTION Киноквиз Караганда

Автономный, 100% бесплатный self-hosted WhatsApp бот для бронирования столиков, ведения базы команд и проведения безопасных рассылок.

Построен на библиотеке **[@whiskeysockets/baileys](https://github.com/WhiskeySockets/Baileys)** (прямое подключение по протоколу WhatsApp Web Multi-Device без сторонних платных сервисов вроде GreenAPI, Twilio или WPPConnect).

---

## 🚀 Основные возможности

1. **Бесплатность и независимость**:
   - Никаких абонентских плат ($0/мес).
   - Подключается напрямую к номеру организатора (`+7 701 186 31 90` или отдельной SIM-карте).
2. **Двойная визуализация QR-кода при первом входе**:
   - В терминале (ANSI QR-код).
   - В веб-интерфейсе: откройте в браузере `http://localhost:3000` и отсканируйте камерой WhatsApp на телефоне.
3. **Интерактивный диалог бронирования (FSM)**:
   - Пошаговый сбор данных: Название команды ➔ Количество игроков (2–10) ➔ Выбор игры из актуального расписания ➔ Имя капитана ➔ Фирменная карточка подтверждения.
   - Главное меню с навигацией: актуальное расписание, место проведения (То Место), правила и стоимость (3000 ₸), контакты.
   - Автоматический сброс сессии при бездействии > 20 минут.
4. **Мгновенная интеграция с сайтом**:
   - Автоматически распознает шаблонные сообщения с лендинга `action-kinoquiz-krg.web.app` («Здравствуйте! Хочу забронировать стол...») и сразу регистрирует команду в базе без лишних вопросов.
5. **Локальная база данных SQLite**:
   - Хранит историю броней, уникальные команды, контакты капитанов и логи рассылок.
   - Файл базы данных: `data/kinoquiz.db`.
6. **Оповещения организатора в Telegram**:
   - При каждом бронировании в Telegram-чат организаторов мгновенно приходит карточка с деталями, суммой депозита/оплаты и кликабельной ссылкой на WhatsApp капитана (`wa.me`).
7. **Безопасная рассылка и защита от блокировок (Anti-Ban)**:
   - Очередь сообщений с рандомизированной задержкой 3–7 секунд между отправками.
   - Имитация набора текста («печатает...» в течение 1–2 секунд).
   - Поддержка отписки («СТОП») и возобновления подписки («СТАРТ»).
8. **Автоматическое напоминание в день игры (Вторник 12:00)**:
   - Встроенный планировщик `node-cron` по вторникам в 12:00 (время Караганды UTC+5) находит подтвержденные брони на сегодняшнюю игру и отправляет капитанам персональные напоминания.

## 📦 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что у вас установлен Node.js (версия 20 или 22+):
```bash
cd whatsapp-bot
npm install
```

### 2. Настройка переменных окружения
Скопируйте шаблон конфигурации `.env.example` в `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` и настройте параметры (при необходимости):
- `PORT=3000` — порт веб-интерфейса QR-кода.
- `TELEGRAM_BOT_TOKEN=` — токен бота от `@BotFather` для оповещений.
- `TELEGRAM_CHAT_ID=` — ID чата/группы организаторов.

### 3. Запуск бота
```bash
npm start
```

### 4. Авторизация (сканирование QR-кода)
1. Откройте **WhatsApp** на телефоне.
2. Перейдите в **Настройки** ➔ **Связанные устройства** ➔ **Привязка устройства**.
3. Наведите камеру на QR-код в консоли либо откройте страницу **`http://localhost:3000`** в любом браузере и отсканируйте QR оттуда.
4. После сканирования сессия сохранится в папке `auth_info_baileys/`. При следующих запусках QR-код сканировать не потребуется!

## 🛠 Полезные команды CLI

В проект встроен удобный инструмент управления:

```bash

# Экспортировать все брони в файл Excel / CSV
npm run export:csv

# Показать актуальные игры, спарсенные из каталога Instagram
npm run games

# Запуск полного набора автотестов (185 тестов)
```

## 🌐 Веб-интерфейс и API

Когда бот запущен, доступен локальный сервер:
- **`http://localhost:3000`** — панель статуса и сканирования QR-кода.
- **`http://localhost:3000/api/status`** — JSON-статус бота (онлайн, номер телефона, аптайм).
- **`http://localhost:3000/api/export/csv`** — мгновенное скачивание свежего CSV-файла со всеми бронями (поддерживает кириллицу в Excel благодаря UTF-8 BOM).

## 🔒 Безопасность и приватность

- Папка `auth_info_baileys/` содержит приватные криптографические ключи WhatsApp сессии. Она автоматически добавлена в `.gitignore` и никогда не попадет в репозиторий.
- Файлы базы данных `data/*.db` и экспорты `exports/*.csv` содержат персональные данные капитанов и также защищены правилами `.gitignore`.

## 🕒 Круглосуточная работа (24/7)

Для постоянной работы бота на сервере (любой VPS на Linux или домашний компьютер/ноутбук) рекомендуется использовать менеджер процессов **PM2**:

```bash
# Установка PM2
npm install -g pm2

# Запуск бота в фоновом режиме с автоперезапуском при сбоях
pm2 start src/index.js --name "kinoquiz-bot"

# Настройка автозапуска при перезагрузке системы
pm2 startup
pm2 save

# Просмотр логов
pm2 logs kinoquiz-bot
```
